# React Product Dashboard

This is a small React application built to demonstrate React's core mental model.

## File Organization
- `src/App.jsx`: Root component, manages state.
- `src/components/ProductList.jsx`: Renders the list.
- `src/components/Product.jsx`: Displays individual product.
- `src/components/Card.jsx`: Layout wrapper using children prop.

## Challenges Faced
- Lifting state up to App.jsx.
- Understanding how to pass props and map data.
